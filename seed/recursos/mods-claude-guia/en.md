A mod is a small add-on that changes how Claude Code looks and works: a band above your prompt, a side panel, buttons, even a mini-game while Claude works. Anthropic launched them on October 1, 2026 (Claude Code 2.1.287). This guide brings together nine to try.

## What the guide includes

One page per mod with **what it does, why it matters, what you should know, the install lines and the link to its code**. Plus two ready-to-copy prompts: one to **build your own mod** and another so your assistant reviews your setup and tells you **which ones suit you**.

| # | Mod | What it does |
|---|---|---|
| 01 | Savvy Progress | See live what each Claude helper is doing and what it costs. |
| 02 | Claude Skins | Changes the look of Claude Code across seven themes. |
| 03 | You Should Know | A second agent that warns you about what you might miss. |
| 04 | Filetree | Your project's file tree next to the chat. |
| 05 | Cache Tax | Stops you before a message that would cost a cold-cache reload. |
| 06 | Blast Radius | Holds risky commands and shows what they would delete. |
| 07 | Reflect | Turns your corrections into saved rules. |
| 08 | Terminal Browser | A browser next to your chat, inside the terminal. |
| 09 | Replay Theater | Replays each Claude edit, one diff at a time. |

## Before installing any mod

A mod **isn't sandboxed**: it runs with your permissions, so it can read and write files, start programs and make network requests. Only install mods from people you trust and review them first. The guide explains how.

Mods work in the Claude Code terminal and in the Code tab of the desktop app. They don't work in the regular Claude chat or in cloud sessions.
