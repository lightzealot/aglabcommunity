Um mod é um pequeno complemento que muda a aparência e a forma de trabalhar do Claude Code: uma faixa acima do seu prompt, um painel lateral, botões, até um minijogo enquanto o Claude trabalha. A Anthropic lançou os mods em 1º de outubro de 2026 (Claude Code 2.1.287). Este guia reúne nove para testar.

## O que o guia inclui

Uma página por mod com **o que faz, por que importa, o que você deve saber, as linhas de instalação e o link para o código**. Além disso, dois prompts prontos para copiar: um para **criar seu próprio mod** e outro para seu assistente revisar seu ambiente e dizer **quais servem para você**.

| # | Mod | O que faz |
|---|---|---|
| 01 | Savvy Progress | Veja ao vivo o que cada ajudante do Claude faz e quanto custa. |
| 02 | Claude Skins | Muda o visual do Claude Code com sete temas. |
| 03 | You Should Know | Um segundo agente que avisa sobre o que você pode deixar passar. |
| 04 | Filetree | A árvore de arquivos do seu projeto ao lado do chat. |
| 05 | Cache Tax | Interrompe antes de uma mensagem que custaria recarregar um cache frio. |
| 06 | Blast Radius | Retém comandos arriscados e mostra o que apagariam. |
| 07 | Reflect | Transforma suas correções em regras salvas. |
| 08 | Terminal Browser | Um navegador ao lado do chat, dentro do terminal. |
| 09 | Replay Theater | Revê cada edição do Claude, um diff por vez. |

## Antes de instalar qualquer mod

Um mod **não é isolado**: roda com suas permissões, então pode ler e escrever arquivos, iniciar programas e fazer requisições de rede. Instale apenas mods de pessoas de confiança e revise antes. O guia explica como.

Os mods funcionam no terminal do Claude Code e na aba Code do app de desktop. Não funcionam no chat normal do Claude nem nas sessões na nuvem.
