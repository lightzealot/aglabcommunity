Does everything you make with Claude stay lost inside a chat? You can now **install an artifact as an app** on your Mac or Windows computer: it gets its own window and icon, and opens like any other program. Here are the official link, the step-by-step and **10 apps with their prompts** to ask for today.

=> [Claude Help Center: install an artifact as an app](https://support.claude.com/en/articles/18516354-install-an-artifact-as-an-app)

## What you need (checked on Nov 26, 2026)

| Item | Value |
|---|---|
| Status | Beta |
| Plans | Free, Pro, Max, Ultra, Team and Enterprise |
| Software | Claude Desktop for Mac or Windows, version 6.28899.0 or later |
| Not available on | Web, mobile or Linux |
| To open the app | You need to be online and signed in to Claude Desktop |

## Install it in 4 steps

1. Ask Claude for the app in a chat and open the **artifact** in the main Claude Desktop window.
2. Open the artifact's **title menu**, or **right-click** it.
3. Select **"Install as app"**. It is also under **Share**.
4. Confirm with **"Install"**.

Don't see it? Update: on Mac, **Claude > Check for Updates**; on Windows, **menu (☰) > Help > Check for Updates**.

## Where your app lives

- **Windows:** in the Start menu (Claude Apps folder) and as a desktop shortcut.
- **Mac:** in the Claude Apps folder inside the Applications folder in your home folder. Spotlight finds it too. To keep it in the Dock: right-click the icon, **Options > Keep in Dock**.

## Permissions

The app has to ask before using each of these. You answer **Allow** or **Don't allow**.

| Permission | What the app can do |
|---|---|
| Notifications | Notify you while you use other apps |
| Keyboard shortcuts | Respond to key combinations while you use other apps |
| Float over other windows | Draw above them and read where your cursor is |
| Menu bar (Mac) or system tray (Windows) | Show an item there while it is open |
| Full access to this computer | Run programs and read, change or delete your files without asking each time |

**Be careful with full access.** Anthropic doesn't review apps before you install them. Grant it only if you trust everyone who wrote the app, and test on **copies** of your files first. To change a permission: on Windows, right-click the title bar and select **Permissions**; on Mac, click the app name in the menu bar.

## 10 apps to ask Claude for today

These are starting ideas: copy the prompt, try it and ask for changes. We didn't test them one by one, so results may vary.

### 1. Floating teleprompter

```
Build me a teleprompter app that floats over my other windows. I want to paste my script, control speed and font size, and pause with the space bar.
```

### 2. Pomodoro in the tray or menu bar

```
Build me a Pomodoro timer that lives in the system tray (or the Mac menu bar), with 25 minutes of focus, a 5 minute break and a notification at each change.
```

### 3. Stretch reminder

```
Build me a small app that reminds me to stretch every hour with a notification and a different short exercise each time.
```

### 4. Rename photos by date

```
Build me an app that renames the photos in a folder by date. Before changing anything, show me the list of changes, ask me to confirm and let me undo.
```

This one asks for full access: test it on a copy.

### 5. Idea catcher with a shortcut

```
Build me a notes app that opens with a keyboard shortcut, saves each idea with its date and lets me search and copy them.
```

### 6. Always-visible daily list

```
Build me a daily to-do list in a small window that floats above the others, with at most 3 priorities on top and a progress bar.
```

### 7. Quote builder for your clients

```
Build me an app to quote my services: I add services with prices, choose quantities, apply discount and taxes and copy the quote ready to send.
```

### 8. Launch countdown

```
Build me a countdown for my launch with a tray or menu bar icon, a to-do list and a notification every morning while it is open.
```

### 9. Tidy your Downloads folder

```
Build me an app that sorts a Downloads folder by file type. First show me what it will move, never delete anything and let me undo.
```

This one asks for full access: test it on a copy.

### 10. Hook factory

```
Build me an app where I type my video topic and Claude suggests 10 hooks that start with a pain point, with a button to copy each one.
```

Requests the app makes to Claude count toward your plan limits.

## Good to know

- It is in **beta**: it may change.
- The installed app is still your artifact: if you edit it, the app changes and Claude asks for permissions again.
- Artifacts made from templates such as **Docs, Slides or Sheets** can't be installed.
- On **Team**, it is on by default but full access stays off until an admin enables it. On **Enterprise**, the whole feature is off until an owner turns it on.
- Building the app and its requests to Claude count toward your plan limits.
- To uninstall: **File > Apps** in Claude Desktop, pick the app and select **Uninstall**.
