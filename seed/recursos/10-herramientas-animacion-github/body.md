¿Abriste un repo de animación en GitHub y no supiste qué descargar? Aquí tienes las **10 herramientas gratuitas** del carrusel, con su enlace y una ruta para elegir por dónde empezar según lo que quieras crear. Datos tomados de GitHub el 24 de noviembre de 2026.

## Anima tus dibujos (2D)

| Herramienta | Para qué sirve | Enlace |
|---|---|---|
| Pencil2D | Dibuja cuadro a cuadro y usa la piel de cebolla para ver el fotograma anterior | [github.com/pencil2d/pencil](https://github.com/pencil2d/pencil) |
| OpenToonz | Organiza escenas con Xsheet y línea de tiempo | [github.com/opentoonz/opentoonz](https://github.com/opentoonz/opentoonz) |
| Synfig Studio | Anima por capas y deja que el programa calcule los cuadros intermedios | [github.com/synfig/synfig](https://github.com/synfig/synfig) |

## Dale movimiento a tu web

| Herramienta | Para qué sirve | Enlace |
|---|---|---|
| Friction | Crea gráficos en movimiento y expórtalos como SVG animado | [github.com/friction2d/friction](https://github.com/friction2d/friction) |
| Theatre.js | Ajusta animaciones 3D y de interfaz desde una línea de tiempo visual | [github.com/theatre-js/theatre](https://github.com/theatre-js/theatre) |
| SVG.js | Anima íconos, formas y trazos con JavaScript | [github.com/svgdotjs/svg.js](https://github.com/svgdotjs/svg.js) |

| Herramienta | Para qué sirve | Enlace |
|---|---|---|
| FreeMoCap | Captura movimiento 3D con cámaras, sin traje especial | [github.com/freemocap/freemocap](https://github.com/freemocap/freemocap) |

## Construye una toma de VFX

| Herramienta | Para qué sirve | Enlace |
|---|---|---|
| OpenVDB | Trabaja con volúmenes 3D como humo y nubes (es una biblioteca de C++, pensada para programadores) | [github.com/AcademySoftwareFoundation/openvdb](https://github.com/AcademySoftwareFoundation/openvdb) |
| Natron | Combina capas y efectos con un editor de composición por nodos | [github.com/NatronGitHub/Natron](https://github.com/NatronGitHub/Natron) |

## Por dónde empezar

| Quiero crear… | Empieza con |
|---|---|
| Mi primer dibujo animado | Pencil2D |
| Una escena 2D completa | OpenToonz o Synfig Studio |
| Movimiento para mi web | SVG.js (íconos) o Theatre.js (3D e interfaz) |
| Gráficos en movimiento | Friction |
| Efectos para un juego | Effekseer |
| Mover un personaje con mi cuerpo | FreeMoCap |
| Efectos de cine | Natron (y OpenVDB si programas en C++) |

## Lo que debes saber

- **Revisa la licencia antes de usarlo para un cliente.** Muchas son GPL o AGPL, que tienen condiciones si compartes o vendes algo derivado del programa.
- **Theatre.js se actualiza poco:** su último cambio es de agosto de 2024. Funciona, pero no esperes mejoras rápidas.
- **OpenVDB no es un programa con ventanas**, es una biblioteca para programadores en C++.
- Son proyectos de código abierto de otras personas, no míos ni de Anthropic. Instálalos desde su sitio oficial.
