Você abriu um repositório de animação no GitHub e não soube o que baixar? Aqui estão as **10 ferramentas gratuitas** do carrossel, com seus links e um roteiro para escolher por onde começar conforme o que você quer criar. Dados tirados do GitHub em 24 de novembro de 2026.

## Anime seus desenhos (2D)

| Ferramenta | Para que serve | Link |
|---|---|---|
| Pencil2D | Desenhe quadro a quadro e use o papel de cebola para ver o quadro anterior | [github.com/pencil2d/pencil](https://github.com/pencil2d/pencil) |
| OpenToonz | Organize cenas com Xsheet e linha do tempo | [github.com/opentoonz/opentoonz](https://github.com/opentoonz/opentoonz) |
| Synfig Studio | Anime por camadas e deixe o programa calcular os quadros intermediários | [github.com/synfig/synfig](https://github.com/synfig/synfig) |

## Dê movimento ao seu site

| Ferramenta | Para que serve | Link |
|---|---|---|
| Friction | Crie gráficos em movimento e exporte como SVG animado | [github.com/friction2d/friction](https://github.com/friction2d/friction) |
| Theatre.js | Ajuste animações 3D e de interface em uma linha do tempo visual | [github.com/theatre-js/theatre](https://github.com/theatre-js/theatre) |
| SVG.js | Anime ícones, formas e traços com JavaScript | [github.com/svgdotjs/svg.js](https://github.com/svgdotjs/svg.js) |

## Capture movimento e crie efeitos

| Ferramenta | Para que serve | Link |
|---|---|---|
| FreeMoCap | Capture movimento 3D com câmeras, sem roupa especial | [github.com/freemocap/freemocap](https://github.com/freemocap/freemocap) |
| Effekseer | Crie faíscas, fumaça e outros efeitos de partículas para jogos | [github.com/effekseer/Effekseer](https://github.com/effekseer/Effekseer) |

## Construa uma cena de VFX

| Ferramenta | Para que serve | Link |
|---|---|---|
| OpenVDB | Trabalhe com volumes 3D como fumaça e nuvens (é uma biblioteca C++ para programadores) | [github.com/AcademySoftwareFoundation/openvdb](https://github.com/AcademySoftwareFoundation/openvdb) |
| Natron | Combine camadas e efeitos com um editor de composição por nós | [github.com/NatronGitHub/Natron](https://github.com/NatronGitHub/Natron) |

## Por onde começar

| Quero criar… | Comece com |
|---|---|
| Meu primeiro desenho animado | Pencil2D |
| Uma cena 2D completa | OpenToonz ou Synfig Studio |
| Movimento para meu site | SVG.js (ícones) ou Theatre.js (3D e interface) |
| Gráficos em movimento | Friction |
| Efeitos para um jogo | Effekseer |
| Mover um personagem com meu corpo | FreeMoCap |
| Efeitos de cinema | Natron (e OpenVDB se você programa em C++) |

## O que você deve saber

- **Confira a licença antes de usar para um cliente.** Muitas são GPL ou AGPL, que têm condições se você compartilhar ou vender algo derivado do programa.
- **O Theatre.js é pouco atualizado:** a última alteração é de agosto de 2024. Funciona, mas não espere melhorias rápidas.
- **O OpenVDB não é um programa com janelas**, é uma biblioteca C++ para programadores.
- São projetos de código aberto de outras pessoas, não meus nem da Anthropic. Instale pelo site oficial.
