Did you open an animation repo on GitHub and not know what to download? Here are the **10 free tools** from the carousel, with their links and a path to choose where to start depending on what you want to create. Data taken from GitHub on November 24, 2026.

## Animate your drawings (2D)

| Tool | What it is for | Link |
|---|---|---|
| Pencil2D | Draw frame by frame and use onion skin to see the previous frame | [github.com/pencil2d/pencil](https://github.com/pencil2d/pencil) |
| OpenToonz | Organize scenes with Xsheet and a timeline | [github.com/opentoonz/opentoonz](https://github.com/opentoonz/opentoonz) |
| Synfig Studio | Animate by layers and let the program calculate the in-between frames | [github.com/synfig/synfig](https://github.com/synfig/synfig) |

## Give your website motion

| Tool | What it is for | Link |
|---|---|---|
| Friction | Create motion graphics and export them as animated SVG | [github.com/friction2d/friction](https://github.com/friction2d/friction) |
| Theatre.js | Tune 3D and interface animations from a visual timeline | [github.com/theatre-js/theatre](https://github.com/theatre-js/theatre) |
| SVG.js | Animate icons, shapes and strokes with JavaScript | [github.com/svgdotjs/svg.js](https://github.com/svgdotjs/svg.js) |

## Capture motion and create effects

| Tool | What it is for | Link |
|---|---|---|
| FreeMoCap | Capture 3D motion with cameras, no special suit | [github.com/freemocap/freemocap](https://github.com/freemocap/freemocap) |
| Effekseer | Create sparks, smoke and other particle effects for games | [github.com/effekseer/Effekseer](https://github.com/effekseer/Effekseer) |

## Build a VFX shot

| Tool | What it is for | Link |
|---|---|---|
| OpenVDB | Work with 3D volumes like smoke and clouds (a C++ library for programmers) | [github.com/AcademySoftwareFoundation/openvdb](https://github.com/AcademySoftwareFoundation/openvdb) |
| Natron | Combine layers and effects with a node-based compositing editor | [github.com/NatronGitHub/Natron](https://github.com/NatronGitHub/Natron) |

## Where to start

| I want to create… | Start with |
|---|---|
| My first animated drawing | Pencil2D |
| A full 2D scene | OpenToonz or Synfig Studio |
| Motion for my website | SVG.js (icons) or Theatre.js (3D and interface) |
| Motion graphics | Friction |
| Effects for a game | Effekseer |
| Move a character with my body | FreeMoCap |
| Film-style effects | Natron (and OpenVDB if you code in C++) |

## What you should know

- **Check the license before using one for a client.** Many are GPL or AGPL, which have conditions if you share or sell something derived from the program.
- **Theatre.js is rarely updated:** its last change is from August 2024. It works, but don't expect fast improvements.
- **OpenVDB is not a program with windows**, it is a C++ library for programmers.
- These are open source projects by other people, not mine or Anthropic's. Install them from their official site.
