# 5 prompts para mejorar tus fotos con ChatGPT

Andrés Gómez · @andresgomez.ia

## Instrucciones de uso

1. Abre ChatGPT.
2. Adjunta la fotografía que quieras mejorar.
3. Copia y pega el prompt que necesites.
4. Revisa el resultado antes de guardarlo.

## Prompt 1 · Dale un acabado de cámara profesional

```
Actúa como un retocador fotográfico profesional. Edita la foto que suba para que parezca tomada con una cámara de formato completo y un lente de 85 mm. Analiza la dirección de la luz, el balance de color, la profundidad del fondo y el encuadre. Aplica una profundidad de campo natural, luces y sombras equilibradas, colores realistas y un encuadre limpio. Mantén el rostro, el cuerpo y la ropa sin cambios.
```

## Prompt 2 · Corrige la luz y las sombras

```
Actúa como especialista en iluminación para edición fotográfica. Corrige la iluminación de la foto que suba sin que parezca editada. Analiza la exposición, las sombras demasiado marcadas, las zonas sobreexpuestas y los tonos de color causados por las luces interiores. Aplica una iluminación suave y uniforme, recupera los detalles de las zonas claras, ilumina ligeramente las sombras y ajusta el balance de blancos a tonos neutros. Mantén a todas las personas exactamente como están.
```

## Prompt 3 · Limpia el fondo

```
Actúa como editor fotográfico especializado en fondos. Limpia el fondo de la foto que suba. Analiza los objetos que distraen, el desorden, las personas que aparecen de fondo y los patrones demasiado llamativos detrás del sujeto. Elimina las distracciones, reconstruye las áreas vacías de forma natural, suaviza ligeramente el fondo y ajusta la iluminación para que el sujeto permanezca exactamente igual.
```

## Prompt 4 · Dale colores más naturales

```
Actúa como especialista en color para fotografía. Aplica a la foto que suba una corrección de color uniforme y natural. Analiza los tonos existentes, los verdes y azules, el contraste y el ambiente general. Aplica colores equilibrados y precisos, tonos intensos pero creíbles, un contraste suave y un sutil aspecto cinematográfico. Después, describe los ajustes para que pueda repetirlos en mis próximas fotos.
```

## Prompt 5 · Mejora el encuadre y el acabado

```
Actúa como editor fotográfico especializado en preparar imágenes para redes sociales. Prepara la foto que suba para publicarla. Analiza la composición, la línea del horizonte, la posición del sujeto y la plataforma en la que la publicaré. Endereza el horizonte, aplica un encuadre basado en la regla de los tercios, mejora ligeramente la nitidez, reduce suavemente el ruido y prepara los tamaños de exportación para una publicación y una historia.
```
