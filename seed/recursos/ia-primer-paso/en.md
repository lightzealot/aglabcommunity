A simple structure to start getting better answers from an AI.

## You don't need to learn 20 tools
If you're just getting started with artificial intelligence, start with a single tool and use it to solve a real problem. You can begin, for example, with ChatGPT.

## The most common mistake
Many people write something like:

> "Write an email for a client."

The AI can answer, but it has very little information to know exactly what you need.

## Use this structure
### 1. What you need
Explain clearly what you want to achieve.

> "I need to reply to a client."

### 2. Context
Give it the information it needs to understand the situation.

> "The client is upset because their order is two days late."

### 3. Result
Tell it how you want to receive the answer.

> "I want the reply to be professional, friendly and short."

## Now put it all together
Instead of "Write an email for a client", try:

> "I need to reply to a client who is upset because their order is two days late. I want a professional, friendly and short reply."

**What I need → context → result.**

## Template to copy
```text
I need [WHAT I WANT TO ACHIEVE].
The context is [IMPORTANT INFORMATION].
I want the result to be [HOW I WANT THE ANSWER].
If you need more information to answer correctly, ask me before continuing.
```

## Try it yourself
Think of a task you do often: writing an email, organizing information, learning something, summarizing a document or coming up with ideas.

First, ask the AI the way you normally would. Then do it again using WHAT I NEED + CONTEXT + RESULT and compare the two answers.

## What to remember
Learning artificial intelligence doesn't start with memorizing tools. It starts by asking yourself: "What problem do I want to solve?"

Pick a concrete task, try the instruction and review the answer.
