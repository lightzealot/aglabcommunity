# 3 repositorios de GitHub para mirar antes de pagar tu próxima web

Andrés Gómez · @andresgomez.ia

Consultado el 31 de octubre de 2026. Fuente: README y FAQ de cada repositorio. Confirma las condiciones de cada servicio en su fuente.

Antes de montar todo, comprueba las condiciones de cada servicio y guarda copias de seguridad.

## 1. FreeDomain (DigitalPlat)

Registro gratuito de dominios con extensiones como .dpdns.org, .us.kg, .qzz.io, .xx.kg y .qd.je, más una guía para aprender DNS. El repositorio oficial está en la organización DigitalPlatDev.

Enlace oficial: https://github.com/DigitalPlatDev/FreeDomain

Qué revisar:

- Busca un nombre disponible en el panel y lee las condiciones antes de registrar.
- No es un .com: es otra extensión, así que revisa qué condiciones tiene.
- Su FAQ indica un dominio por cuenta por defecto.
- Necesitas un servicio DNS que te dé servidores de nombres; ellos no avalan ninguno.

## 2. Free for Dev (ripienaar)

Lista de servicios con plan gratuito para quien desarrolla: hosting, bases de datos, correo, analítica y más. Solo incluye servicios con plan gratuito real, no pruebas, y está pensada para perfiles técnicos.

Enlace oficial: https://github.com/ripienaar/free-for-dev

Qué revisar:

- Anota qué necesitas: visitas, almacenamiento, correos al mes.
- Compara los límites de cada plan con esa lista antes de elegir.
- Revisa si el plan gratuito cambia o caduca: la lista la mantiene la comunidad y las ofertas cambian.
- Mira dónde quedarían tus datos y cómo los sacarías si te mudas.

## 3. Awesome Selfhosted (awesome-selfhosted)

Catálogo de software libre que puedes alojar en tu propio servidor: notas, archivos, tareas, blogs, analítica y más. También tiene versión web en awesome-selfhosted.net.

Enlace oficial: https://github.com/awesome-selfhosted/awesome-selfhosted

Qué revisar:

- Tú decides cómo instalar y mantener cada aplicación.
- El software puede ser libre, pero el servidor y el tiempo de mantenimiento pueden costar.
- Antes de elegir una app, mira si sigue activa y quién la mantiene.
- Configura copias de seguridad antes de guardar datos importantes.

## Checklist antes de montar tu web

- [ ] Anoté qué necesito: dominio, hosting, correo, datos.
- [ ] Leí las condiciones de cada servicio que voy a usar.
- [ ] Comparé los límites del plan gratuito con mi uso real.
- [ ] Sé quién es dueño del dominio y cómo lo conservo.
- [ ] Sé cuánto cuestan el servidor y el mantenimiento si alojo yo mismo.
- [ ] Tengo copias de seguridad y sé cómo restaurarlas.
- [ ] Tengo un plan B si el servicio gratuito cambia o desaparece.
