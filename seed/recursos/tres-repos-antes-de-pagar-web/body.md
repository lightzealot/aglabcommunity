Tres repositorios de GitHub para mirar antes de pagar tu próxima web: **FreeDomain** (dominios gratuitos con otras extensiones), **Free for Dev** (servicios con plan gratuito) y **Awesome Selfhosted** (aplicaciones que puedes alojar tú). Abajo descargas el PDF para el celular y la versión editable con la checklist.

**Consultado el 31 de octubre de 2026** en los README y la FAQ de cada repositorio. Las condiciones de cada servicio cambian: confírmalas en su fuente.

## Qué incluye

1. **FreeDomain (DigitalPlat):** busca un nombre disponible y revisa las condiciones. No es lo mismo que comprar un .com.
2. **Free for Dev:** compara los límites de cada plan con lo que necesitas antes de elegir.
3. **Awesome Selfhosted:** tú decides cómo instalar y mantener cada aplicación. El software puede ser libre, pero el servidor y el mantenimiento pueden tener costo.
4. **Checklist** de siete puntos antes de montar tu web.

Antes de montar todo, comprueba las condiciones de cada servicio y guarda copias de seguridad.
